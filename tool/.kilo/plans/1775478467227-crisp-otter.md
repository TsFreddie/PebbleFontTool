# Plan: Regional Glyphs Support

## Overview

Add capability to load and modify regional glyph mappings from `../../regional_mapping.json` (relative to `tool/` directory, resolves to `/mnt/data/Projects/tumbled/regional_mapping.json`).

## Regional Mapping File Structure

Expected structure for `regional_mapping.json`:

```json
{
  "<codepoint>": {
    "<region>": "<suffix>"
  }
}
```

Example:

```json
{
  "12345": {
    "JP": "jp",
    "CN": "cn"
  }
}
```

This means codepoint 12345 has regional variants:

- `JP` region uses suffix `"jp"` → glyph file `12345-jp.txt`
- `CN` region uses suffix `"cn"` → glyph file `12345-cn.txt`

## Implementation Steps

### 1. Add Type Definitions

In `src/lib/server/loader.ts`:

```typescript
export type RegionSuffix = Record<string, string>;
export type RegionalMapping = Record<number, RegionSuffix>;
```

### 2. Add Loader Function

In `src/lib/server/loader.ts`:

```typescript
export const loadRegionalMapping = (): RegionalMapping => {
  const data = fs.readFileSync("../../regional_mapping.json", "utf-8");
  const raw = JSON.parse(data);
  // Convert string keys (codepoints) to numbers
  return Object.fromEntries(
    Object.entries(raw).map(([cp, regions]) => [parseInt(cp), regions]),
  );
};
```

### 3. Add API Endpoint for Regional Mapping

Create `src/routes/api/regional/+server.ts`:

- `GET`: Returns the full regional mapping
- `POST`: Saves modified regional mapping (for future extensibility when mapping becomes non-identity)

### 4. Client-side Integration

In `src/lib/index.ts`:

- Add `loadRegionalMapping()` function to fetch via API
- Store regional mapping in a Map/cache

### 5. Glyph Loading Enhancement

When loading a project, also load regional glyphs from files matching `<codepoint>-<suffix>.txt`.

For example, if regional mapping has:

```json
{
  "12345": { "JP": "jp", "CN": "cn" }
}
```

Then load `12345-jp.txt` and `12345-cn.txt` as regional glyphs for codepoint 12345.

In `Glyph` interface, add optional `regionalSuffix?: string` field to distinguish regional variants:

```typescript
export interface Glyph {
  codepoint: number;
  variant?: string;
  regionalSuffix?: string; // e.g., "jp", "cn"
  advance: number;
  shapes: ShapeLookup[];
}
```

### 6. Load Regional Mapping with Project

- `loadProject()` should call `loadRegionalMapping()` and include the mapping in the returned `Project`
- Add `regionalMapping: RegionalMapping` field to `Project` interface

### 7. Frontend Loads Regional Mapping via API

Create new endpoint `GET /api/regional` that returns the regional mapping.

In `src/lib/index.ts`, add `loadRegionalMapping()` function to fetch and cache the regional mapping:

```typescript
const regionalMappingCache = new Map<string, RegionalMapping>();

export const loadRegionalMapping = async () => {
  const response = await fetch("/api/regional");
  if (!response.ok) throw new Error("Failed to load regional mapping");
  const buffer = new Uint8Array(await response.arrayBuffer());
  const mapping = unpack(buffer) as RegionalMapping;
  return mapping;
};
```

### 8. Highlight Missing Regional Glyphs

In the glyph grid UI, for each glyph with regional variants:

- Check if the regional glyph file exists for each suffix
- If a regional glyph file is missing (e.g., `12345-jp.txt` doesn't exist), apply a distinct background color to that glyph cell to indicate it needs attention

Implementation approach:

- Add a function `checkRegionalGlyphExists(font, codepoint, suffix)` or include existence info in project data
- Add CSS class or style for "missing regional variant" indication (e.g., red/orange background tint)
- The UI component displaying glyphs should check `project.regionalMapping[codepoint]` and verify each regional variant exists

## Key Design Decisions

- **File format**: JSON for human-editability and widespread support
- **Regional variant storage**: Uses existing glyph file naming convention (`{codepoint}-{suffix}.txt`)
- **Read-only initially**: The mapping file may only need read access; write support added if needed
- **Lazy loading**: Regional mapping loaded on demand, not with every project load
